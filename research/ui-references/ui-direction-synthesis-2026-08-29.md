# 《瓦罗王的餐桌》市场 UI 参考汇总与审美方向迭代

调研日期：2026-08-29  
结论范围：主解谜界面、国家完成后的故事／档案界面、关卡册；不改变既定的无猜规则或叙事基线。

## 结论先行

原先四稿中，**04「碑刻拓印／田野账册」依然拥有最好的布局骨架**，但不应原样落地。三组独立调研的结论相同：它应迭代为：

> **叠印图档／后世修复台**——玩家面对的不是一件陈列在博物馆里的古物，而是一张正在被后世档案修复者校订的帝国地图。

这不是把界面做成无文化的极简产品，而是把文化感从石碑、卷轴、尺子、夹子和泛古典装饰，转移到本项目独有的**地图套印、帝国覆写、后世校订、地名留存与国家档号**上。棋盘、国界和当前约束先被读到；完成一国后，历史才以完整的档案页开口说话。

## 当前产品与评审口径

- **对象：** 浏览器逻辑解谜《瓦罗王的餐桌》的“内海七国”主解谜页。
- **受众：** 希望获得无猜、可长时间推演的逻辑体验，同时愿意在完成节点阅读历史叙事的成年／青年玩家。
- **页面的单一任务：** 让玩家一眼看见当前数字到底约束了同一国家内的哪些格，并可立即落下亮／暗／擦除标记。
- **硬约束：** 数字统计以自身为中心、仅限同一国家、最多 `3×3` 范围内的亮格；粗国界是规则而不是装饰。晚宴、亡国记录与地图档案是完成回报，不能常驻抢占棋盘。

## 新方向：叠印图档／后世修复台

### 视觉论点

一张地图中同时存在三层有效历史：**底图的地方轮廓、帝国覆写的国界、后世修复者的校订线**。玩家每完成一个国家，第三层才在该区域的边缘留下一个可检索、但不遮挡数字的“留存痕迹”。这比通用的羊皮纸和古董道具更专属于《瓦罗王的餐桌》。

### 信息架构

```text
页首：作品名 · 章节 · 已完成数 · 关卡册／档案入口
索引条：七国标签 + 极淡完成印记
工作带：亮格 1 · 暗格 2 · 擦除 3 · 必然步骤 · 检查 · 清错

                 20×20 主棋盘（绝对主体）
           数字 · 粗国界 · 亮/暗/未知 · 当前线索
                   精确的同国 3×3 范围

按需层：规则解释／国家档案／晚宴节点／故事卡
完成态：地图边缘的低噪套印与可重开条目
```

桌面端不要永久维持右侧晚宴长文；常驻信息只有一个紧凑计数和档案入口。故事、留存物与晚宴在完成国家时占据独立卡页或抽屉，关闭后始终能从该国的地图位置重开。

### 视觉 token 契约

| 语义 | 建议颜色／材料 | 使用边界 |
| --- | --- | --- |
| 底图／未知格 | `#E7E4DA` 暖灰图纸／石灰浆平面 | 单格几乎无纹理。 |
| 墨线／正文／国界 | `#1D2A30` 深石墨蓝黑 | 国界比普通组件线粗一级。 |
| 亮格 | `#D9CAA0` 干燥石灰金 | 与未知格有明度与边框双重差异。 |
| 暗格 | `#31484E` 深靛 | 与亮格在明度、图形和文字反色上均可分辨。 |
| 当前线索／冲突 | `#B33B34` 朱砂 | 只用于单点高优先级状态，绝不做通用按钮色或国家身份色。 |
| 有效范围／可信提示 | `#4F8177` 铜绿 | 只用于代码严格裁剪后的同国 `3×3` 交集，配合角括号／标签。 |

国家身份不在棋盘单元格中铺大色块；最多使用低饱和的边缘套印、筛选标签细标和完成后的微型地图证据。这样亮／暗是玩家填入的内容状态，朱砂／铜绿是当前推理的界面状态，两套语义不会相互抢占。

### 字体、动态与无障碍

- **标题／章节：** 有印刷感的中英衬线展示体，只用于页首与故事卡标题。
- **规则／按钮／正文：** 高 x-height 的中英无衬线；**数字／快捷键：** 具有清楚 tabular figures 的等宽或半等宽 UI 字体。
- 单格落笔只做 120–180ms 的平面“套印显影”；完成国家才允许 250–400ms 的局部校订线浮现。尊重 `prefers-reduced-motion`。
- 所有颜色状态额外提供图形、描边、文字和 `aria` 语义；纹理与展示字体必须可降低或替换。这与 *Pentiment* 官方提供 Easy Read 字体和高对比选项的做法一致。[官方无障碍说明](https://pentiment.obsidian.net/)

### 必须避开的四件事

1. 在功能面常驻石碑、卷轴、旧纸、夹子、尺子、硬币和其他没有玩法职责的“古物道具包”。
2. 将真实文明的文字、宗教符号、建筑或纹样作为七国的快捷文化标签。
3. 让国家颜色、金边或材质噪点与朱砂当前线索、铜绿有效范围竞争。
4. 用装饰性大虚线代替代码计算出的、可验证的同国 `3×3` 范围。

## 最终设计判断

**继续选 04 的结构，但废止它的“田野账册／展柜”拟物。** 新方向比原方案更贴合“地图比帝国活得更久”的故事：玩家操作的是一套会记录、覆写、修订与保留地方痕迹的图档系统，而不是一张被崇拜的古地图。
