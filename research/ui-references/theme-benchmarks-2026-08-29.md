# 《瓦罗王的餐桌》同题材 UI 画风基准

- 调研日期：2026-08-29
- 目的：为“后世档案修复者复原一张短命帝国全盛地图；解开一国，地图、晚宴与亡国档案同步推进”的包装寻找**题材相邻但玩法不同**的成熟游戏 UI 参照。
- 范围：只讨论材料语言、字体、叙事／玩法信息层级、地图／档案／日志界面；不以玩法相似为筛选条件。
- 方法：优先核查开发商官网、官方 press kit、发行商官网和发行商维护的 Steam 商店页。下文的「官方说明」均有一手链接；「截图观察」只描述所链接官方图库或商店截图中可见的内容，不以媒体评测作为视觉事实来源。

## 结论先行

既有的 **04「碑刻拓印／田野账册」仍是四稿中最合适的主方向**，但本轮对照后应把它从泛化的“考古风”收紧为：

> **一份后世制作、可实际操作的帝国地图档案（posthumous map dossier），而非一张被装饰的古旧羊皮纸。**

四款参照共同说明：历史感最可靠的来源不是大量污渍、花纹或伪文字，而是让**内容的载体就是界面功能**——地图可以索引，册页可以归档，边界可以检索，注记可以是证据。对本项目而言，棋盘和国界必须永远先于材料纹理；故事卡和档案才承载较浓的文化／历史细节。

| 作品 | 与项目相邻的题材 | 最值得研究的 UI 母题 | 对主棋盘的直接适配 |
| --- | --- | --- | --- |
| *Heaven’s Vault* | 考古、失落文明、破译铭文、非线性遗址叙事 | 原始证据 + 候选释义的上下文浮层 | 中：适合作为“档案注记”的打开方式，不可变成不确定的主规则 |
| *Pentiment* | 历史文献、社会／政治变迁、手稿与覆写 | 文献成为叙事场景；华丽书写与易读文字并存 | 高：适合故事卡、章节册页和可访问性原则 |
| *Return of the Obra Dinn* | 后来者调查一段已结束的历史；保险档案、名单、船图 | 工作簿／示意图就是推理工具 | 很高：最适合“地图即证物、国界即检索索引” |
| *Chants of Sennaar* | 古老语言、分隔的文化、记录与破译 | 活页笔记本把插图证据和符号分类分开 | 高：适合七国的章节色与档案页，不适合满屏高饱和或伪文字 |

## 1. Heaven’s Vault：考古界面应显示“推断过程”，但不侵入核心操作

**题材成立性。** Inkle 将本作定义为考古科幻冒险：考古学家 Aliya 探索失落遗址、翻译铭文，以揭示 Nebula 的过去；官方也明确说明译文会反馈到叙事中，且翻译未必正确。[官方游戏页](https://www.inklestudios.com/heavensvault/) [官方 press kit 的概述](https://www.inklestudios.com/press/heavensvault/)

**可观察 UI 要点。**

1. **探索时 HUD 极少。** 官方 Switch 截图里，场景占据绝大多数画面；底部只留下 `Map`、对话／评论动作和对应按键，当前可交互物以一句上下文文字落在场景内。它把信息层级压成“世界 → 当前动作 → 导航”。[官方截图组（Switch 6 张）](https://www.inklestudios.com/press/heavensvault/)
2. **翻译不是跳离世界的设置页。** 官方截图中的释义界面使背景失焦、中央放大原始字形，上方显示 `Related words`，下方才给出少量候选词；明亮的字形是视觉焦点，灰色的既有线索退到第二层。[官方截图组](https://www.inklestudios.com/press/heavensvault/)
3. **2D 人物 + 3D 遗址，UI 不再额外模拟旧物。** 官方说明其美术把手绘 2D 与 3D 环境混合；截图可见文字与交互图标使用干净的现代屏幕层，而不是把每一个操作按钮做成碎石或羊皮。[官方说明与截图](https://www.inklestudios.com/press/heavensvault/)

**可借鉴。** 把“地图原件／某国留存物”的阅读做成一次有焦点的证据浮层：打开时压暗棋盘，中央只呈现一条清晰的标题、国家轮廓、留存物与“归档”动作；关闭后回到同一地图位置。对 `瓦罗王的餐桌` 来说，它可用于故事卡前的短暂“发现感”，而不必扩张常驻侧栏。

**不可照搬。** 本作的译文不确定性是玩法。当前项目强调无猜、精确的 3×3 计数，不能把数字、国界或提示解释成“有多种可能的古文字”；也不要用不可读的假字形替代真实数字或中文／英文正文。

## 2. Pentiment：文献质感必须让位给可读性

**题材成立性。** Obsidian 将本作置于 16 世纪宗教和政治巨变中，明确说明其世界受彩饰手稿和木刻版画启发；玩家的调查会影响社区未来。[官方游戏页](https://pentiment.obsidian.net/) [官方发布公告](https://www.obsidian.net/news/obsidian/obsidian-entertainment-announces-pentiment)

**可观察 UI 要点。**

1. **页面既是场景也是文字容器。** 官方截图里，建筑、人物和对话框都像同一页手稿／木刻上的构成；另一个截图直接以跨页插画和上方成行文字作为谈话背景。对话仍放在浅色、边缘明确的气泡中，因此叙事文字没有被插画吞没。[官方网站的截图与制作说明](https://pentiment.obsidian.net/)
2. **历史字体仅承担“声音”，不独占信息。** 官方页面明确承认其风格字体和书写效果可能影响阅读，并提供 Easy-read font 选项以关闭部分效果；同时支持调节字号和高对比模式。[官方无障碍说明](https://pentiment.obsidian.net/)
3. **粗轮廓、有限色块和纸色底统一了界面。** 官方截图可见黑褐色描边、低复杂度的平面色块，以及从纸页中长出来的标题／对话牌；这比贴一层陈旧纸纹更像一份被实际阅读的历史文献。[官方截图](https://pentiment.obsidian.net/)

**可借鉴。** 让故事卡、档案列表和章节册页采用“可翻阅的文献”版式：页眉只放小型分类（国家／年代／卷号），标题可用有性格的衬线展示字体，正文和按钮必须保留现代可读字形。叙事页面可以拥有轻微的边框、行线、页码与边注，但棋盘数字不要套用书法或仿手写字体。

**不可照搬。** 不要借用中世纪欧洲手稿的宗教图像、黑体花体或具体历史纹章；项目是原创的“内海七国”，不是巴伐利亚修道院。更重要的是，Pentiment 自己的无障碍做法证明：装饰字体应有可读替代，而不能成为功能文字的唯一表达。

## 3. Return of the Obra Dinn：把档案做成操作系统，而不是奖励库

**题材成立性。** Lucas Pope 的官方页将玩家置为 1807 年受命登船的东印度公司保险调查员；玩家面对的是一艘已无船员、事件已经结束的船，职责是评估损失。这是“后世／后来者从残存记录重建事实”的强相邻结构。[官方网站](https://obradinn.com/)

**可观察 UI 要点。**

1. **作品主动选择极简色彩。** 官方页把它称为 “An Insurance Adventure with Minimal Colour”；截图中书册、平面图、人物和场景都被压入几乎单色的点阵／印刷效果，因而“文件”而非“环境装饰”成为记忆点。[官方网站与官方图库](https://obradinn.com/)
2. **书封是数据的身份牌。** 官方截图可见 `Lost at Sea, 1803`、船名、吨位、船长和船员数以印刷排版组织在封面上；这不是可有可无的过场，而是调查档案的入口和可信度语气。[官方图库](https://obradinn.com/)
3. **空间图同时是导航、名单和时间线。** 官方截图中的船舱示意图带有甲板名称、舱位与人物标识，上方明确写出时间流向；信息并未另塞进多层窗口，而是依附在可定位的空间结构上。[官方图库](https://obradinn.com/)

**可借鉴。** 这是最接近本项目的参照：将每国的“完成态”嵌回地图本体，使国界既是 3×3 的规则边界，也是档案条目的索引。故事卡关闭后，地图上仍应留下一个可点击的、低噪声的完成印记；档案列表按地图位置／进度编号检索，而非变成一摞脱离地理的成就卡。

**不可照搬。** 不建议复制其一位色点阵、19 世纪公司文书口吻或东印度公司联想。当前棋盘还必须同时区分未知、亮、暗、七国、当前线索和有效范围；全单色会牺牲状态编码。应借它的**精确示意图和书目秩序**，不是复制它的像素／殖民档案外观。

## 4. Chants of Sennaar：文化差异应进入“章节与档案”，不能挤进数据面

**题材成立性。** 官方商店页说明玩家在受巴别塔神话启发的世界中，观察并破译古老语言；五个民族拥有各自的技术、建筑和文化视觉身份，笔记本负责记录每个符号和推断。[发行商维护的 Steam 页面](https://store.steampowered.com/app/1931770/Chants_of_Sennaar/) [发行商官网截图页](https://www.focus-entmt.com/en/games/chants-of-sennaar)

**可观察 UI 要点。**

1. **笔记本将“已见证据”和“待分类数据”分离。** 官方截图中左侧跨页是黑白线描的情境记录，右侧是排列在圆点网格上的符号筹码；世界背景被弱化。即使玩家尚未读懂语言，也能看出哪里是来源、哪里是操作对象。[官方 Steam 截图](https://store.steampowered.com/app/1931770/Chants_of_Sennaar/)
2. **未知文字被放在叙事位置，而不是全局 UI 字体。** 场景截图中角色的对话泡泡显示陌生字形，但收藏／整理页面仍使用稳定的框架、卡片和留白。这让“看不懂”成为游戏内的对象，而不是让整个界面难读。[官方 Steam 截图](https://store.steampowered.com/app/1931770/Chants_of_Sennaar/)
3. **每层世界用强烈却受控的局部色群区分。** 发行商官方图库可见黄、红、青、粉等大片扁平色和欧陆漫画式排线；另一组场景则明显转入冷青与暗红。它把文化差异优先赋予空间和章节，而不是给每一个按钮换一种样式。[官方截图图库](https://www.focus-entmt.com/en/games/chants-of-sennaar)

**可借鉴。** 七国可以各有一枚低饱和矿物色、一个抽象地貌／制图符号和一张完成后的档案页；这些差异集中于地区筛选、地图边缘索引、故事卡页眉和完成印记。主棋盘只维持统一的亮／暗／未知数据语法，避免把国家身份和逻辑状态混为一谈。

**不可照搬。** 不能让全界面长期保持高饱和章节色，也不要制造一套貌似真实但不可读的“内海文字”。前者会与线索、提示和错误态竞争，后者既影响本地化，也会让虚构文化被简化成装饰性符号。

## 对当前 04「碑刻拓印／田野账册」结论的校正

### 保留

1. **布局仍以 04 为准。** Obra Dinn 证明“空间结构兼作索引”最贴合国界即逻辑边界的设定；04 的中心棋盘、明确工具和独立档案入口，仍优于把地图挤成背景的 01／03 或过分强调航海图册的 02。
2. **石灰岩／炭墨／深靛底盘仍成立。** 它不绑定某个真实王朝，能传达保存、拓印和地图实体；与 Obra Dinn 的低色秩序、Pentiment 的纸页层级相容。
3. **朱砂当前线索、灰绿有效范围继续作为唯一高饱和交互信号。** 这符合四个参照的共同规律：世界可有材料个性，当前操作必须有单一、清楚的视觉焦点。

### 优化为“地图档案三层”，不只是“田野账册”

| 层级 | 视觉职责 | 建议形式 | 参考缘由 |
| --- | --- | --- | --- |
| 1. 可玩的正文 | 20×20 格、数字、粗国界、亮／暗／未知、当前线索、同国 3×3 范围 | 灰白石页／炭墨网格；格内无花纹；亮暗状态只靠高明度差与形状／边框辅助 | Obra Dinn 的示意图精确性；Pentiment 的“装饰不吃掉文字” |
| 2. 地图索引 | 国家完成态、地区筛选、进度、可重读入口 | 国界外缘使用低饱和矿物色和小型“档号／印记”；已完成国只加极淡拓印，不覆盖数字 | Obra Dinn 的空间索引；Chants 的章节身份 |
| 3. 叙事证物 | 晚宴节点、亡国故事、留存物、结局 | 在模态册页中使用一张清晰的文献卡：页眉、国家轮廓、正文、留存物、归档动作；打开时弱化棋盘 | Heaven’s Vault 的上下文浮层；Pentiment／Chants 的文献页 |

### 可执行的审美规则

- **把“年代层”做成状态，而不是脏污。** 一国完成后可出现淡墨复原线、帝国制图标记和留存物索引；这些变化应沿国界和边缘发生，绝不铺在数字下方。这样才回应“地图比帝国活得更久”。
- **字体实行双轨。** 标题／卷号可用温和的衬线展示字体；规则、按钮、数字、快捷键和长正文保留高 x-height 的现代中英文字体。后续实施应提供字号调节、足够的色彩对比和可关闭的纹理／装饰效果，借鉴 Pentiment 的可读替代原则。
- **七国的文化差异用制图语言表达。** 每国最多分配“一种矿物色 + 一种抽象地貌线／索引符号”，并把它们放在标签、地图边缘与档案页。不要用真实文字、宗教符号、国旗、服饰或随意拼贴的“异域纹样”。
- **卡片是节奏停顿，不是常驻喧闹侧栏。** 完成国家时先让地图发生永久、克制的状态变化，再打开册页；关闭后读者总能从地图回到该条记录。这保留了现在的叙事规范，也避免与巨型棋盘争夺横向空间。
- **不要从参照里借错东西。** 不复制 Obra Dinn 的 1-bit 效果、Pentiment 的欧洲中世纪图像、Heaven’s Vault 的不确定译文机制，或 Chants 的伪文字／满屏荧光配色。应借它们如何把信息、载体与故事绑在一起。

## 采用优先级

1. **主界面：04 的结构 + Obra Dinn 式“地图即索引”原则。**
2. **故事与档案：Pentiment 的可读文献页 + Heaven’s Vault 的聚焦浮层。**
3. **七国差异：Chants 的“章节拥有视觉身份”原则，但压缩到低饱和的矿物色／制图符号。**
4. **无障碍是画风的一部分：** 与当前的明确快捷键和棋盘状态保持一致，历史感绝不可以成为辨认数字、国家边界或提示范围的代价。
