# 欧洲历史题材的风格化 UI 参考（2026-08-29）

## 目的与评分口径

这一组不是要把《瓦罗王的餐桌》做成“欧洲历史游戏”，而是寻找如何把**后世对帝国遗图的校订**做得有历史意识、又不落入博物馆拟物或商业 4X HUD 的办法。

统一的相关性评分将用于后续九款样本横向比较：

- 题材／叙事接近度：45%（后帝国、地方叙事、复原真相、地图／档案）
- UI 可迁移性：25%（能否服务中心棋盘、当前线索和完成后叙事）
- 风格化独特性：30%（是否能避开主流商业写实、泛奇幻与标准策略 UI）

分数是“对本项目设计决策的相关度”，不是对游戏品质的评价。

## 这组带来的判断

1. **历史感不等于古物感。** *Golden Idol* 的力量来自“玩家改写已发生之事”的结构；*Inkulinati* 的力量来自图页本身有生命；都比石碑、卷轴、封蜡、纹章更适合当前故事。
2. **可用的欧洲历史感是媒介感。** 可取的是手工排版、边注、套印、拼贴、校样和局部修订的视觉语法，不是欧洲文明的符号库。
3. **对本项目最有价值的是‘反凯旋的更正’。** 地图不是帝国的战功展示，而是后人把被覆盖的七国重新对准、重新归档的证据版面。

## 对新原画方向的直接启发

新方向应和“叠印图档／后世修复台”的温静档案桌面拉开距离：

> **失国者的校样／第二版地图**：一张曾服务帝国凯旋叙事的印刷地图，正在被后世档案员用各国遗留证词校正。它是平面的、多色套印的、略带错位的；不是考古展柜，也不是战争指挥台。

后续原画可把棋盘作为最大的“印版”，让焦点线索出现时两层颜色严格套准到该线索的同国 `3×3` 有效格；完成一个国家时，边缘才短暂露出当地版本的图例与一条地方记录。这样，风格化服务的是规则可见性，而非装饰。
