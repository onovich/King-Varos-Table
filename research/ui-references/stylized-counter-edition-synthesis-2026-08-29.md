# 九款追加参考的汇总：下一轮 UI 原画方向（2026-08-29）

## 新结论

在既有的「叠印图档／后世修复台」之外，下一轮应当尝试一个**视觉语法完全不同**、但不改变故事伦理和玩法骨架的方向：

> ## 被删王名／第二版地图
>
> 一张曾被瓦罗帝国印成“统一版”的地图，正在由后世档案员重新排成第二版。帝国的名称、边线和占有语气是可被校掉的第一层印刷；每复原一个国家，地方旧名、路线或证词才重新进入版面。

它不是博物馆工作台，不是羊皮纸、木书或考古展柜，也不是征服者的指挥台。它是一张**反凯旋的、平面的、套色错版的编年印刷页**：高对比、版式锋利、但主棋盘始终可读。

这就是本轮的新的总方向。它从历史的“材料质感”转向历史的“谁有资格命名、编号、出版地图”的冲突，因而能明显区别于此前的静谧档案修复台，并更贴近本作“地图比帝国活得更久”的落点。

## 评分方式

所有九作在同一尺度上重新加权，以便跨题材比较：

| 维度 | 权重 | 为什么这样取值 |
| --- | ---: | --- |
| 叙事／题材接近度 | 40% | 本作必须保持“帝国已覆灭、后世修复记录、地方历史未消失”的站位。 |
| 主棋盘 UI 可迁移性 | 25% | 20×20、同国裁剪 `3×3` 的无猜推演不能被主题牺牲。 |
| 风格化与非主流性 | 35% | 用户明确偏好鲜明的风格化；本项刻意高于一般产品评估中的美术权重。 |

加权分不是作品品质排名，而是“应当对《瓦罗王的餐桌》这一张新原画有多大影响”的设计权重。

### 三组的结论，不是三套皮肤

- **反乌托邦组**告诉我们：制度的压迫感来自记录、分类、编号与删改，不必用霓虹、监控或红绿裁决。[《Papers, Please》官方 press kit](https://www.papersplea.se/presskit/) 、[《Citizen Sleeper》官网](https://citizensleeper.com/CS-1)
- **帝国／权力组**告诉我们：帝国应被处理为可质疑的旧叙事；国家完成的回报应是地方证词，而不是扩张或战果。[《The Life and Suffering of Sir Brante》官方页](https://store.steampowered.com/app/1272160/The_Life_and_Suffering_of_Sir_Brante/) 、[Stoic 的《The Banner Saga》官方页](https://stoicstudio.com/banner-saga)
- **欧洲历史组**告诉我们：可以借出版、版画、边注、证据重组这些“媒介语法”，但不可挪用真实欧洲的宗教、王室、纹章或语言符号。[《The Case of the Golden Idol》官方页](https://store.steampowered.com/app/1677770/The_Case_of_the_Golden_Idol/) 、[《Inkulinati》官方页](https://store.steampowered.com/app/957960/Inkulinati/)

## 与现有结论的比较

| 维度 | 既定方向：叠印图档／后世修复台 | 新方向：被删王名／第二版地图 |
| --- | --- | --- |
| 主隐喻 | 档案员在地图上校订遗留物。 | 档案员在重新出版一张曾服务帝国的错误地图。 |
| 视觉气质 | 冷静、细线、低对比、近工作台。 | 高对比、扁平、剪裁感、套色错版、编辑性强。 |
| 历史感来源 | 三层地图与修复痕迹。 | 谁的名字被印上、划掉、重新对准的出版冲突。 |
| 叙事动作 | 恢复／归档。 | 删去帝国的单一说法，重新把地方留进第二版。 |
| 最大风险 | 落入博物馆展柜式拟物。 | 滑成政治宣传海报或版画纹理压过规则。 |
| 正确的控制方式 | 减少道具，保留精确范围。 | 限制颜色和版画笔触到棋盘外，保留精确范围。 |

两个方向应并行保留：前者适合全局主线的沉静、可信；后者适合用户强烈偏好的风格化，并可作为另一稿原画的明确差异化试验。

## 可直接交给原画的设计 brief

### 一句视觉命题

**不是“帝国地图被完成”，而是“帝国的第一版地图终于被校正”。**

### 构图

```text
页首：第二版地图 · 复原批次 · 七国索引
      一条被细线划掉的、不可读的帝国册名（装饰，不能假装功能）

工具带：亮格 1 · 暗格 2 · 擦除 3 · 检查／提示／清错
        低矮、平面、明确；不使用金属按钮、火漆、卷轴或徽章

                    20 × 20 主棋盘／印刷版
          最大、无地貌纹理、粗国界、清晰数字、亮暗未知状态
          当前数字：朱砂单点标识
          有效范围：严格同国裁剪的套准角括号／高亮边线

页边：当前国家的两行版本对照（帝国册名 / 地方留名）
按需：完成后才打开一张“编年证词”卡；关闭时绝不侵占棋盘
```

### 风格化机制

1. **套印错位不是噪点，而是状态。** 帝国旧边线与后世校线只在国家外缘、页首与完成卡出现 1–2px 的轻微错位；单元格内部保持纯净。
2. **当前线索应有一记“套准”。** 玩家聚焦一个数字时，一层细的校订色从外部滑入并只对准代码算出的同国 `3×3` 有效格；范围必须是规则结果，而不能是一块漂亮但错误的装饰框。
3. **完成国家是“名字重现”，不是占领。** 统一帝国名退成低对比底印；地方旧名、迁徙线或一条证词通过白底反白小条目出现。没有旗帜升起、金色勋章、领土填色扩张或胜利章。
4. **故事媒介是单张编年证词。** 左边是抽象地貌／边界小切片，右边是 70–110 字记录和一个时间节点；它是独立阅读态，主棋盘时不常驻。

### 色彩与字体契约

| 角色 | 建议 | 使用范围 |
| --- | --- | --- |
| 工作底 | 骨白纸 `#E7DCC0` | 平坦，不做做旧脏纹理。 |
| 墨线／国界 | 夜蓝黑 `#171D2B` | 国界 2–3px，普通组件 1px。 |
| 帝国第一版 | 低饱和靛蓝 `#3D577B` | 只在版面外缘、旧名和已完成国的底印。 |
| 地方第二版 | 干玫瑰 `#B66C74` | 只用于校订层与完成叙事，不充当格子状态。 |
| 当前线索／冲突 | 朱砂 `#C84435` | 单点高优先级；不作为通用确认、按钮或国家色。 |
| 精确有效范围 | 铜绿 `#43877D` | 仅限严格裁剪后的同国 `3×3`，另加角括号／说明。 |
| 亮／暗／未知 | 与上述“叙事色”独立的明度、描边、斜线／点状辅助语法 | 任何色觉下都能区分。 |

- 页首可用有雕版感、但不仿真实语系或手写古文的展示字；按钮、规则、数字和快捷键用高可读无衬线与 tabular figures。
- 所有版画感必须来自几何化刻线、排版和有限错位，**不是**覆满纸张的纹理滤镜。
- 动态只有局部的“套准”与完成国家时的“错版回位”；遵守 `prefers-reduced-motion`，且不以动态传递唯一信息。

### 非目标：这张原画绝不应出现

- 卷轴、石碑、封蜡、羽毛笔、硬币、尺子、皮书、厚重金属按钮。
- 皇冠、军旗、现实纹章、宗教符号、真实文明的文字或伪文字。
- 4X 的资源条、城市模型、单位头像列、外交图、科技树、领土征服反馈。
- 赛博朋克黑底霓虹、监控框、扫描线、红绿审批章或倒计时。
- 任何在棋盘格内和数字争夺注意力的木刻人物、地貌、装饰边框或大面积国家色。

## 原画验收清单

1. 缩至 `1280 × 720` 仍能在一秒内定位棋盘、粗国界、当前数字和精确 `3×3` 范围。
2. 移除所有叙事文本后，亮／暗／未知、提示与检查依旧可以无歧义操作。
3. 完成国家时，玩家感到“保留了一段被抹掉的记录”，而不是“占领了一块土地”。
4. 它与四张既有概念图中的档案桌面、航海图、镶嵌石材、碑刻账册在一眼观感上明显不同。
5. 无需真实历史文化符号，也能从套印、删改、再版、地方证词读出文化历史感。
