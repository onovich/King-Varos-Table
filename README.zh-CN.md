# King Varo's Table

[English](README.md)

King Varo's Table 是一款在浏览器中运行的逻辑谜题：玩家需要复原瓦罗王短命帝国的分裂版图。当前章节可以依靠确定性推理完成，不需要猜测。

![King Varo's Table social preview](docs/social-preview.png)

## 玩法

每个数字统计以自身为中心、包含数字格本身的最多 3×3 范围内共有多少亮格。粗国界会裁剪这个范围，边界另一侧的格子永远不参与计数。玩家需要把所有格子判断为亮或暗，逐步复原整张地图。

当前 20×20 章节包含七个不规则国家。完成一个国家会推进王室晚宴并揭示一份亡国记录；七份记录全部读完后，后世尾声会收入档案。

## 操作

当前界面仅提供简体中文，下列按钮名与游戏内文字一致。

| 操作 | 控制方式 |
| --- | --- |
| 标记亮格 | 左键点击，或聚焦格子后按 Enter |
| 标记暗格 | 右键点击或 Shift+点击 |
| 把格子恢复为未知 | 再次执行当前的亮格或暗格操作 |
| 请求一个必然步骤 | 点击 `给我一个必然步骤` |
| 检查或清理棋盘 | 点击 `检查当前推理` 或 `清除错误答案` |
| 重新开始或重读故事 | 点击 `重新开局` 或地图档案按钮 |

## 已实现

- 七个连通的不规则国家，以及受国界裁剪、覆盖 0—9 的数字线索；
- 可见的单数字直接推理路径，并由 MiniZinc 验证每个国家不存在第二解；
- 基于玩家当前盘面的提示、矛盾报告、区域筛选和错误答案清理；
- 晚宴节点、仅首次弹出的亡国记录、章节尾声、可重读档案和版本化本地存档；
- 公开关卡数据包含地图和线索，但不包含目标答案。

## 开发

需要：

- Python 3；
- Node.js 与 npm；
- 生成关卡和执行完整唯一性检查时，需要带 Gecode 求解器的 MiniZinc。

运行本地原型：

```powershell
npm start
```

然后打开 <http://localhost:4173/>。

运行测试：

```powershell
npm test
```

重新生成仓库中的关卡：

```powershell
npm run generate
```

生成命令会覆盖 `web/data/demo-level.json`；只要 MiniZinc 未能证明所有国家唯一，命令就会失败。

## 状态

版本 `0.3.0` 是一个可在本地游玩的七国单章节原型。界面仅提供简体中文，目前主要面向桌面指针操作；Enter 可以标记亮格，但尚未实现完整的纯键盘或触屏控制。项目也没有公开托管的在线试玩地址。

本次 README 审视中，26 项测试全部通过。最终美术、正式故事文本和多章节战役仍待制作。
