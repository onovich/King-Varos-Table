# King Varo's Table

[English](README.md)

《瓦罗王的餐桌》是一个可在浏览器中运行的无猜 3×3 邻域计数谜题原型，舞台是一位短命君王被国界分割的帝国版图。

![King Varo's Table social preview](docs/social-preview.png)

## 项目简介

每个数字统计以自身为中心、包含数字格本身的最多 3×3 范围内共有多少亮格。粗区域边界会裁剪这个范围：边界另一侧的格子永远不参与计数。玩家需要把所有格子判断为亮或暗，逐步复原整张版图。

仓库中的示例关卡是一张 20×20 棋盘，包含七个不规则、互不串线的连通国家和完整的 0—9 数字范围。它可以只依靠题面中单个数字的直接推理从空盘完成；MiniZinc 还会独立检查每个国家不存在第二组答案。

第一段叙事垂直切片已经可玩：完成一个国家会推进王室晚宴、永久改变地图、弹出独立的亡国故事卡，并把记录收入可重读档案；棋盘和叙事进度会通过版本化本地存档恢复。更完整的方向见[叙事包装规范](docs/design/narrative-packaging.md)。

## 操作方法

| 操作 | 控制方式 |
| --- | --- |
| 标记亮格 | 左键点击，或聚焦格子后按 Enter |
| 标记暗格 | 右键点击，或 Shift+点击 |
| 把已标记格恢复为未知 | 再做一次相同的亮格或暗格操作 |
| 请求一个必然步骤 | 点击 **给我一个必然步骤** |
| 检查当前盘面 | 点击 **检查当前推理** |
| 清除全部错误标记 | 点击 **清除错误答案** |
| 清空棋盘 | 点击 **重新开局** |
| 重读已完成国家的故事 | 点击 **查看亡国档案** |

提示器会根据玩家当前盘面重新计算：强框只标出一个现在就能结算的数字，弱框标出它被区域边界裁剪后的有效邻域。默认提示不会悄悄升级为双线索作差。

当前界面只有简体中文，尚未实现触屏专用操作。

## 已实现功能

- 一张 400 格棋盘上的七个不规则连通国家；
- 经区域边界裁剪的 3×3 数字线索，覆盖完整的 0—9；
- 由关卡验收和网页提示共同使用的单数字直接推理器；
- 用阻塞目标答案、寻找第二解的 MiniZinc 严格唯一性检查；
- 基于玩家当前状态的矛盾检查、聚焦提示、区域筛选、重置和错误答案清理；
- 国家完成、晚宴里程碑、仅首次弹出的亡国故事卡、可重读档案和版本化本地进度；
- 只包含区域和线索、不公开隐藏答案的关卡 JSON；
- 保留给研究使用、但不会冒充基础提示的集合差集分析器。

## 本地运行

需要：

- Python 3；
- Node.js 与 npm，用于仓库命令和由 Node 驱动的 JavaScript 测试；
- 生成或完整验证关卡时，需要带 Gecode 求解器的 MiniZinc。

项目没有声明 npm 依赖。在仓库根目录执行：

```powershell
npm start
```

然后打开 <http://localhost:4173/>。

运行测试：

```powershell
npm test
```

重新生成示例关卡：

```powershell
npm run generate
```

生成命令会覆盖 `web/data/demo-level.json`，并要求 MiniZinc 明确证明唯一性。超时或求解结果未知都会被视为失败。

本次已在 Python 3.14.3、Node.js 24.13.1、npm 11.8.0、MiniZinc 2.9.7 和 Gecode 6.3.0 环境中完成运行验证；其他版本组合尚未测试。
