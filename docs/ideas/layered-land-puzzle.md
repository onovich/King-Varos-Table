# 多图层土地谜题

状态：Side project 概念停车场
与当前项目关系：不进入《瓦罗王的餐桌》当前玩法或叙事；待本作核心循环和至少一个正式章节打磨成熟后，再迁移到独立项目并重新包装题材。

## 核心机制

一块土地由多个位置完全对齐的网格图层组成，每一层提供自己的谜题和“点亮”含义。

共同规则：

- 每一层都只需要点亮部分格子，不要求填满整个图层。
- 上一层某个坐标可以点亮的前提，是下一层同一坐标已经点亮。
- 因而每个格子不仅受本层谜题约束，还受纵向图层依赖约束。
- 最终答案不是一张平面图，而是一组具有先后或承载关系的叠层结构。

这个机制与《瓦罗王的餐桌》的 3×3 区域计数有亲缘性，但它新增了跨层偏序关系。它可以继续使用局部数字谜题，也可以让每层采用不同谜题；后者需要另行验证学习成本。

## 方向一：时间图层——土地的一季

从下至上依次表示同一块土地在不同时间的状态：

1. 松土；
2. 播种；
3. 施肥；
4. 浇水；
5. 丰收。

同一坐标只有完成前一阶段，才可能进入后一阶段。并非每块松过的土地都必须播种，并非每株作物都一定进入所有后续状态，因此各层点亮集合可以逐层缩小、分叉或留下失败痕迹。

这个方向的优势是因果关系直观，玩家天然理解“先做下层、再做上层”。它适合包装成农事、生态恢复、考古地层中的时代演变，或一个地方跨季节的生活史。

需要验证：

- 各层是否共用一种线索规则，还是每个农事阶段使用不同谜题；
- 玩家能否在没有频繁切层的情况下看懂纵向依赖；
- 某层推理停滞时，下一步究竟来自本层线索还是下层前置条件；
- “没有进入下一阶段”如何与“尚未推理”视觉区分。

## 方向二：空间图层——城市基础设施

从下至上表示同一片城市空间中的不同系统，例如：

1. 水管布线；
2. 道路；
3. 建筑物；
4. 电网。

上一层的设施只能落在得到下一层对应坐标支撑的位置。这样玩家逐层建立一座城市：不可见的地下系统先决定道路和地块，地表结构再决定更高层网络。

这个方向比农事版本更强调系统工程与空间规划，也更容易扩展出不同层使用不同规则的组合谜题。风险是现实语义未必总支持严格的同坐标依赖，例如电网并不一定只能位于建筑正上方；独立项目需要选择抽象程度，避免规则与题材互相反驳。

需要验证：

- 纵向依赖是严格同坐标，还是允许相邻连接、覆盖范围或网络供给；
- 地下层和地上层如何同时查看；
- 各层能否独立回退，以及上层失去支撑后如何处理；
- 完成条件是满足所有层的谜题，还是建成某个目标结构。

## 两个方向共享的原型问题

- 图层数量超过三层后，玩家是否还能维持清晰的心理模型；
- 是否需要爆炸图、剖面图、半透明叠加或小型纵向时间轴；
- 提示系统如何明确说明“本层必然步骤”与“跨层前置条件”；
- 允许部分点亮时，如何定义每层完成及全局完成；
- 关卡生成应先生成顶层目标再向下补足支撑，还是先生成底层再逐层筛选；
- 唯一解需要验证每层自身唯一，还是整个叠层组合唯一。

## 与当前游戏保持边界的理由

《瓦罗王的餐桌》的主题统一点是：一张平面帝国地图、国家边界和被边界裁剪的 3×3 计数是同一件事。多图层机制会把核心注意力转向纵向依赖、时间或基础设施，削弱“完成国家即复原历史版图”的关系。

因此当前只保存机制，不把图层、农事或城市设施写入本作关卡格式。未来迁移时，应建立独立仓库、重新命名、重新选择题材，并把本作成熟后的提示、唯一性验证和关卡生成经验抽象后再复用。

## 迁移触发条件

满足以下条件后再考虑启动独立原型：

1. 《瓦罗王的餐桌》的基础提示和无猜生成规则稳定；
2. 至少完成一个带存档、国家完成和故事卡的正式章节；
3. 已获得关于单层大棋盘节奏和玩家理解成本的试玩反馈；
4. 能为多图层项目单独安排原型范围，而不打断当前游戏制作。
