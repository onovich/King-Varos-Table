# 《瓦罗王的餐桌》叙事包装规范

状态：当前叙事基线；后续剧情、界面与关卡编排应以本文为准  
工作标题：**瓦罗王的餐桌 / King Varo’s Table**  
更新日期：2026-08-28

## 1. 核心提案

玩家在后世修复一张瓦罗王全盛时期的帝国版图。地图上的每个大分区都是一个国家，国界既是世界观中的政治边界，也是谜题中不会跨越的 3×3 计数边界。

作品同时讲述两件事：

1. 一场从开席到散席、按时间向前推进的王室晚宴；
2. 版图上各个国家如何在瓦罗王的扩张中陷落。

这不是逐句双关，也不依赖“吞下一个国家”“城墙像酥皮碎裂”一类文字游戏。两条叙事各自使用字面意义完整地讲清自己的事情，含义来自它们被安排在同一次游玩进程中：玩家一边看见瓦罗王进食，一边亲手补全他的征服图。

## 2. 名称与核心意象

- 中文工作名：`瓦罗王的餐桌`
- 英文工作名：`King Varo’s Table`
- 核心人物：瓦罗王；“霸王”只是设计讨论中的角色类型，不作为正式称号反复写入正文。
- 核心物件：餐桌、餐盘、地图、国界、档案中的亡国记录。
- 核心动作：进餐、复原版图、完成国家、翻开亡国故事卡。
- 核心反差：晚宴是一夜之事，帝国也是短命之物；那张版图却被后世保存下来。

“餐桌”使标题具象、可视，也让国王的饕餮成为征服欲的整体隐喻。标题不需要直接解释数字谜题；玩法说明与视觉展示负责建立地图和计数的联系。

## 3. 玩家视角与世界框架

当前采用“后世档案修复者”框架：玩家接触到的是一张残缺的帝国地图，以及随地图保存下来的宴会纪事和各国档案。玩家不是瓦罗王本人，也不是替他发号施令的将军；玩家做的是复原历史记录，但这个动作会暂时重演帝国扩张的顺序。

这一框架解决三个问题：

- 为什么一张旧地图可以被逐格复原；
- 为什么完成一个国家会出现一张可归档、可重读的故事卡；
- 为什么结局可以跳到后世，说明暴政迅速覆灭而地图仍然留存。

界面不必一开始就解释全部真相。开场可以把对象称为一册未整理完的宴会地图、菜单附图或宫廷旅行记录，让玩家先把注意力放在菜肴、物产、市场和异域风貌上。

## 4. 两条叙事线

### 4.1 晚宴纪事：固定方向的线性主线

晚宴纪事从宾客入席开始，依次经过前菜、主菜、酒宴高峰、过量与疲惫、席散和天明。它必须是一场连续的晚宴，而不是每解开一个国家就重新讲一次相似的用餐段落。

可以描写：

- 菜肴的材料、火候、器皿、气味、温度与口感；
- 侍者换盘、斟酒、撤席和等待下一道菜的动作；
- 瓦罗王食欲、节奏、姿态和身体状态的变化；
- 食材来自怎样的气候、河谷、海港、市场和商路；
- 当地人如何种植、保存、交换和食用这些食物。

这些内容首先必须真的是关于食物和人文地理的文字。它可以让玩家联想到旅行记、宫廷记录或一本带地图的食物志，但不要把军事行动藏进每一句菜肴描写里。

为了允许玩家自由选择国家，晚宴的时间骨架应绑定全局进度，而不是绑定某个固定国家：例如完成第 1、3、6、10 个国家时推进到下一道宴席节点。某个国家的食物资料可以填入当前宴席节点，但“开席—盛宴—疲惫—散席”的时间方向不能倒退。若最终决定采用固定关卡顺序，则可把国家、菜序与宴席节点完全预编排。

### 4.2 亡国故事卡：完成国家后的独立事件

每完成一个国家，必须弹出一张独立故事卡。故事卡不是角落提示，也不是同时出现的第二段旁白；它是玩家完成该国后的正式叙事奖励和一次明确的节奏停顿。关闭后应进入档案，可从地图上的对应国家重读。

故事卡应直接说明该国如何陷落，并保留具体的人与地方，而不是只写“版图又扩大了”。可涉及：

- 首都、港口、河流、关隘、道路与边境地形；
- 政治误判、围困、投降、抵抗、逃亡或内部背叛；
- 被征用的粮食、废弃的市场、改名的街道和中断的节庆；
- 普通人带走、失去或设法保存下来的物件与习俗；
- 帝国记录如何夸大胜利，以及后世档案留下了哪些裂缝。

建议每张卡包含四个稳定部分：

1. `国名 / 首都或代表城市 / 年代位置`；
2. 一段具体场景作为开头；
3. 陷落经过及其人类后果；
4. 一件留存到后世、能回到地图上的物品、习俗或地名。

不同国家可以拥有不同结局：迅速投降、长期围困、宫廷政变、被盟友出卖、主动撤空城市、表面归顺而持续反抗。这样“完成一区”的机械重复不会变成故事重复。

## 5. 两条线如何共同产生含义

### 开场阶段

玩家首先读到真实的菜肴、城市、物产和旅途细节，因此可以合理地以为作品主要讲一场奇异晚宴以及食物背后的文化。不要在标题页或教程里立即解释“每一道菜就是一次征服”。

### 第一次揭示

第一个国家完整解开后，地图发生“陷落”状态变化并弹出第一张亡国故事卡。这里才让玩家明确意识到：餐桌旁的异域物产与地图上的扩张发生在同一段历史中。第一块区域应较小，使这次揭示最好在前 20—30 分钟内发生，而不是把核心叙事承诺延迟数小时。

### 揭示之后

此后不再假装作品只有美食主题。悬念转为：下一国为何陷落、宴席将如何变得更丰盛也更令人不安、瓦罗王会变成什么样，以及完整地图最终意味着什么。

晚宴段落和亡国卡不需要逐项互译。例如，晚宴可以字面写“第三道菜是盐烤河鱼，鱼皮在银盘上迅速失去热气”；紧接着的卡片可以字面写“同一季，河港守军撤离北门”。两段文字的并置已经足够，不必再写“国王吞下了河港”。

## 6. 叙述声音与文学参照

全篇只保留一个统一的叙述者或档案编纂声音，不采用“御用史官一句、后世批注一句”的双声部结构。晚宴纪事与亡国卡可以在版式、篇幅和功能上不同，但不需要两位叙述者互相评论。

参考方向：

- 《马可·波罗游记》提供表层旅行书写的观察维度：城市、人物、货物、市场、道路、风俗与宫廷奇观；
- 卡尔维诺《看不见的城市》提供结构启发：让每座城市或每个国家围绕一个鲜明意象组织，并通过多个独立片段逐渐显出整体；
- 参考的是观察方法、模块结构和主题回响，不直接模仿某位作者的句法、措辞或标志性文风。

建议文风保持清楚、具体、略带冷静的奇异感。幽默可以来自制度的荒谬、礼仪的过度认真和事实之间的反差，不来自密集俏皮话或双关句。

## 7. 明确禁止的写法

- 不写逐句的食物／战争双关；
- 不把国家直接称作菜肴，不写“吞并”与“吞咽”的刻意连用；
- 不用酥皮、切肉、摆盘等词去轻佻比喻城破、死亡或流离；
- 不让每张卡同时出现两种声音，反复替玩家解释讽刺在哪里；
- 不让所有国家只换地名、沿用同一套陷落模板；
- 不把瓦罗王长期写成值得崇拜的胜利者，也不在开场就用道德总结替代故事；
- 不使用“最后一国尚未陷落”作为核心悬念，因为设定中所有国家最终都曾陷落。

## 8. 地图、国家与玩法的统一

- 每个大分区默认对应一个国家；国界裁剪 3×3 计数范围，因此世界边界和逻辑边界是同一件东西。
- 一个国家可通过首都或代表城市进入叙事。这样可以使用城市级的人文细节，同时保持“分区就是国家”的玩法规则。
- 完成国家后，地图颜色、纹章或档案状态发生永久变化；弹卡只是叙事入口，地图本体也必须留下完成痕迹。
- 亮暗格的最终图案应逐步发展为与国家地貌、纹章、器物或历史片段有关的图像，而不是只作为随机噪声。
- 国家可以按地理章节分组，例如内海、盐路、河谷、群岛和高原；章节名称同时帮助菜单、菜序和剧情节奏编排。

## 9. 终局

最后一个可玩国家完成时，玩家看见的不是“尚未陷落的最后一国”，而是瓦罗王帝国全盛期的完整版图和已经结束的整场晚宴。随后才出现后世尾声：这个看似无边的政权很快被推翻，瓦罗王的强盛只是短暂一瞬；被保存下来的地图既记录了帝国自我夸耀的顶点，也成为后人辨认各国遭遇的历史证物。

终局不应把所有苦难简化成一句“正义获胜”。它要让玩家看到：政权消失得很快，但改名、迁徙、失传与幸存的习俗留下了更长的余波。

## 10. 内容生产模板

每个国家至少需要以下字段：

```text
country_id
country_name_zh / country_name_en
capital_or_focus_city
geography
food_and_material_culture
banquet_insert
fall_card_title
fall_card_body
surviving_trace
map_reveal_concept
chapter
completion_order_constraints（可选）
```

全局晚宴另有独立时间表：

```text
arrival → first service → appetite rising → feast at its height
→ excess and fatigue → last course → table cleared → dawn / epilogue
```

先分别检查“晚宴单独读是否连贯”和“每张亡国卡单独读是否成立”，最后才检查两者的并置节奏。任何一条线都不应依赖另一条线替它补全基本事实。

## 11. 尚待原型验证的决定

1. 玩家可以任意选择国家，还是只在章节内自由选择；这会决定宴席节点与国家菜肴如何组合。
2. 第一章国家数量和第一个小国面积，以确保首次陷落在合理时间内发生。
3. 统一叙述者在世界内的身份：无名档案编者、宫廷记录的后世整理者，或只保留无人格的全知叙述。
4. 地图完成后使用纹章、历史颜色还是复原插画表达国家状态。
5. 文字本地化时，英文与中文是同一文本的自然改写，还是共享事实、分别创作；无论选择哪种，都不能靠生硬直译维持句式机关。
