# 棋盘国境线与底图的硬性视觉契约

适用于《瓦罗王的餐桌》所有后续 UI 原画与实现。本文高于任何风格偏好。

## 国境线

1. 每一段国境线都必须落在两个相邻格子的**公共格线**上。
2. 国境线只能水平或垂直地沿格线折转；**不得**斜穿、弯穿、跨越或终止在单元格内部。
3. 国境线的形状应由关卡国家归属数据导出，而不是由美术手绘。原画可示意，但实现必须以程序生成的路径为准。
4. 普通格线与国境线应有明确层级：普通格线 1px 左右，国境线 2–3px；高对比模式下仍需可分辨。
5. 任何地貌线、道路、河流或阴影都不能伪装成国境线，不能比国境线更深或更粗。

## 地形底图

地形图可以存在，作用是帮助玩家把区域读成“国家版图”，类似大型史诗地图的空间感；它不是规则层。

- 它位于单元格填色、数字、格线和国境线之下；单格底色可半透明，但数字必须始终拥有稳定的纯色／半透明遮罩。
- 推荐用低对比地貌：等高线、海湾、山脊、森林块、河道、旧路、云影或版画阴影。它可以跨国家延续，但不能创造新的规则边界。
- 地形细节不得包含可误读为亮／暗状态的规则性方格、标记或高亮色；也不能压低当前数字、键盘焦点、朱砂线索或铜绿有效范围的识别度。
- 主解谜状态下地形对比度应比国境线低一档以上。国家完成后的故事页可使用更完整的地貌插图。

## 功能语义不变

- 当前线索：朱砂或等价的单点高优先级信号；不用于国家身份。
- 有效范围：仅显示代码计算出的“以当前数字为中心、同一国家、最多 `3×3`”交集；使用独立颜色与角括号／描边，不能只是装饰框。
- 亮、暗、未知：除颜色外还需具备明度、描边或图形差异。
- 工具、提示、检查、清错、键盘快捷键和档案入口必须有文字或可访问名称；原画中的抽象图标不能单独承担含义。

## 原画验收

缩至 `1280×720` 时，观察者应先后读到：

1. 棋盘、国境线、数字与亮／暗／未知；
2. 当前线索和精确范围；
3. 工具与即时操作；
4. 最后才是地貌、纹样、故事和环境气氛。

只要任何一条国境线切进格内，或底图让玩家无法区分数字／边界／状态，该稿在可用性维度直接不通过。
