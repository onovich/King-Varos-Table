# 第三轮原画 brief：霸业、盛景、征服、帝王

本轮故意不沿用“后世修复者的冷静档案”气质。目标是探索瓦罗帝国处于巅峰时，如何用视觉把自己呈现为庞大、辉煌、秩序井然、不可违逆的帝王霸业。

这是一种**帝国自我叙述的视觉语言**，不等于把游戏的最终历史立场改成歌颂征服：完成国家后的叙事仍可让地方记忆反驳这张盛世图；主解谜页则先测试“凯旋版帝国地图”的强烈吸引力。

## 共同硬约束

- 中央必须是可读的 `20×20` 主棋盘，至少占画面 55%。
- 国境只能沿水平／垂直公共格线折转，绝不斜切、弯切、穿过或停在格内。
- 地势可铺在棋盘下：大陆、山脉、海湾、河流、道路或城群只能作为低对比背景，不能画成第二套国境，也不得压过数字、格态、国境、当前线索或有效范围。
- 当前线索使用单点朱砂；有效范围必须是程序计算的“同国、中心 `3×3` 交集”，用铜绿和角括号／轮廓表示；亮／暗／未知不只靠颜色区分。
- 工具有清晰文字和快捷键。故事、军团、朝贡等氛围信息只能在棋盘外或按需展开，不能把它做成 4X 资源／兵种控制盘。
- 可以用虚构的帝冠、日轮、凯旋拱、巨像、御座、军旗的**抽象图形**表现帝王气质，但不能挪用真实王朝、宗教、国旗、语系或现成 IP。

## 四条彼此不同的视觉线

1. **日轮凯旋壁画**：帝王的巨幅太阳、凯旋队列和山河壁画；平面、雄伟、暖金／帝国红／天青。
2. **万邦朝贡织幕**：一张盛世织幕将海道、群山、朝贡路线织成地形；深蓝／绯红／鎏金／象牙。
3. **黑曜御座军机图**：冷峻、建筑式的帝国秩序；黑曜、铜金、朱砂与电蓝，强几何但不做赛博 HUD。
4. **宝石马赛克圣城图**：矿彩、玻璃、金箔和巨型广场，最明亮、最盛景化，但边界／数字优先。

## 统一验收

四项各 25 分：可用性、风格化、美观、主题适配。几何国境不合格则整稿不可用；即使合格，边界若不能一眼读出，也会在可用性分重扣。
