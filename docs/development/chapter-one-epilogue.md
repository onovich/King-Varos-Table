# 第一章后世尾声

状态：已实现并验收  
批准日期：2026-08-28
完成日期：2026-08-28

## 目标

补齐“内海七国”地图的叙事终点。玩家完成七国并依次读完七张亡国记录后，先看见瓦罗王全盛时期的完整地图与已经结束的晚宴，再打开一份来自后世的尾声：帝国很快被推翻，版图却留存下来，成为辨认各国遭遇的历史证物。

## 行为约束

1. 七国只是全部完成、但仍有亡国故事尚未关闭归档时，不得提前打开尾声。
2. 七国均完成、七张亡国故事均已归档且当前没有待展示故事时，尾声自动打开。
3. 自动揭示只发生一次；刷新页面不得重复弹出已经看过的尾声。
4. 尾声关闭后进入地图档案，可以反复重读；重读不改变国家、晚宴或尾声进度。
5. 尾声状态纳入版本化本地存档；不完整或自相矛盾的数据应被拒绝。
6. 明确“帝国覆灭”不等于抹平余波：文本同时保留改名、迁徙、失传与幸存习俗的后世痕迹。
7. 重新开局仍是唯一可以清空整章叙事进度的入口。

## 测试边界

- 浏览器逻辑接口：尾声资格判断、一次性归档、非法存档拒绝与合法存档恢复。
- Python 关卡接口：公开关卡包含完整但不泄露答案的尾声内容。
- 用户可见 DOM：语义化尾声对话框、档案回看入口、明确的关闭文案和键盘焦点恢复。

## 本轮不解决

- 第二章或完整战役的章节选择界面；
- 终局插画、动画与音效；
- 英文文本与本地化流程；
- 七国故事正文的商用品质终稿。

## 实现结果

- 尾声资格由公开的战役状态接口判断：七国均完成、七张亡国卡均归档、待展示队列为空且尾声尚未揭示时才成立。
- 最后一张亡国卡关闭后自动打开后世尾声；关闭后写入版本 3 本地存档，刷新不会重复弹出。
- 完整地图档案包含七张国家记录和一条独立的后世尾声；重读不会修改战役状态。
- 尾声对话框使用原生 `dialog`，打开时聚焦关闭按钮，关闭后把焦点交还档案入口。
- 自动化测试共 26 项；浏览器实测覆盖七国真实完成顺序、尾声门槛、归档重读、刷新恢复、控制台错误以及 320/768/1024/1440 px 响应式布局。
