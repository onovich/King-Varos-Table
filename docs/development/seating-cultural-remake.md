# 宴厅座椅与后景：文化依据、取舍与实施

2026-09-09，revision 11。本地执行，未推送。

## 决断

删除旧王座巨幅织物背景和专属框架，不保留为屏风。代码里的原件名为 `Throne textile backdrop`，是吊挂织物而非实体椅背；上轮移走王座却留下专用背景，造成用途不明。本轮没有把它替换为另一块独立大面板，保留建筑原墙，在下部设置连续石质墙裙与实体接缝。

六个侧席属于有身份的宴饮参与者，不当作平民板凳。主座仍是桌端宴席座椅，不能复制教会礼仪王座。七席、桌高及活动范围保持，等级通过构造、材料配额及比例建立。

## 真实资料与适用边界

1. 欧洲拜占庭及后拜占庭古迹中心的 [Household equipment](https://exploringbyzantium.gr/EKBMM/Page?id=44&lang=en&level=2&name=ypomeleti&sub=552)：家具随财力和身份而异，宫廷使用贵金属、象牙等材料；有椅、凳、织物覆盖和用来分隔空间的帷幔。资料覆盖拜占庭时期，引用的研究还包含中晚期图像，不能据此声称新模型是六世纪精确复原。宫廷有帷幔并不证明当前无分隔用途的巨幅背景值得保留。
2. 拉文纳官方文化站的 [Museo Arcivescovile](https://www.ravennacittadelmosaico.it/luoghi/museo-arcivescovile/)：馆藏六世纪马克西米安象牙座椅。它是主教座，适合作为精细镶板与雕刻工艺参照，不适合作为世俗宴席座椅的直接样板。
3. 宾州州立大学图像档案 [Throne of Maximian: Front view with right side](https://digital.libraries.psu.edu/digital/collection/arthist2/id/76526/) 明列木胎覆象牙镶板及宗教图像。借鉴框嵌工艺，排除宗教叙事人物图像。
4. 大都会博物馆 [Byzantine Ivories](https://www.metmuseum.org/essays/byzantine-ivories)：早期拜占庭宫廷象牙工艺背景。少量浅色镶嵌用于表现材料等级，不能以三条巨大浅色板代替雕刻质量。

本作仍是历史启发的架空地中海宴饮／议事空间。直立座椅长桌布置及具体木作尺寸属于游戏设计，不宣称考古复原。车木构件、框嵌面板、低浮雕棕榈叶形属于古典工艺语汇的现代设计组合。

## 已实施

- 六张侧席：连续车木立柱与收分、真实套接铜脚、横撑、座框线脚、内退背板、窄压条、接合处小铜钉；撤掉金色菱形。
- 帝王席：更宽的座框、封闭扶手板、分层冠梁、窄浅色镶嵌和一小块木雕低浮雕；撤掉三联巨大浅色板与弯金线。坐面高度仍与客席相同，不以增高坐面破坏桌椅使用关系。
- 木件 UV 按构件走向组织，复用现有木材颜色、法线和粗糙度贴图，另设椅子用材质参数；坐垫增加织物表面和缝边。运行时材质共享，不增加每椅独立纹理加载。
- 全部模型通过 `tools/Build-BlenderTableware.ps1 -Study Furniture` 隐藏无头生成，Blender 5.2.1 LTS，BelowNormal、双线程。普通模型 336152 字节，主座 553244 字节。并非手工雕刻或扫描模型。
- 既有光源参数、玩法与存档格式不变；删除背景物体后，墙面接受光照的结果自然改变。

## 验证

95 项自动测试通过，包括实际 GLB 数量、主座与桌端净空、侧席资源共享和既有游戏回归。新增实景检查页 `/prototypes/imperial-table/seating-review.html` 使用正式场景和相同 PBR 渲染器，可查看整体、主座与客席；不是单件离线渲染。

网页截图保存在 `screenshots/seating-11-*`。本轮没有重新进行移动设备帧率测量，也不以无头 Blender 成功导出作为美术质量已达标的证明。

实景复核：主座、客席和正式标题远景均已查看，浏览器未报告错误。客席在现有照明下仍偏暗，未为近景额外补光。近景纠正了横梁／立板的木纹方向，以及坐垫缝边的曲线外鼓问题。
