# 宴厅空间与 UI 重规划

2026-09-09。状态：已执行。见 [实施与验证记录](banquet-space-ui-execution.md)。保留照明参数、动态开关和本地光影配置。

## 空间判断

目前同时安排了餐桌端部主座、远处高台王座和巨大帷幔，形成两个权力中心。端部座椅挡在王座与桌面之间，人物若在桌端就坐便背向远处王座；若坐上远处王座，又无法参与海图活动。这是本场景的使用与叙事冲突，不能简单归纳为历史上任何宴厅都禁止王座。

罗马帕拉蒂尼皇宫的 Aula Regia 用于觐见，Cenatio Iovis 用于宴饮，提供了分离两类用途的明确实例。古罗马宴饮常使用卧榻；“十九卧榻厅”的复原也把皇帝的宴饮位置置于主后殿。后者为推测复原，遗址不存，不能当作精确平面证据。

采用“帝王主持的七席宴饮与海图议事厅”，保留直立座椅和长桌，明确属于历史启发的架空改编。拒绝额外遥置的觐见王座。以后若剧情需要觐见场面，应另设空间。

```text
              后壁浅后殿／织物背景
                   帝王宴席主座 ↓
             ┌──────────────────┐
         席  │                  │  席
         席  │     中央海图      │  席
         席  │                  │  席
             └──────────────────┘
                  上菜与镜头方向
```

七席保持现有数量；图示为六个侧席加桌端主席，不据此新增国家或角色。主席仍在桌端地面上，以座椅自身轮廓和背景轴线体现等级，不单独抬高座面造成桌高失配。移除远处王座及其专属多级台阶；后壁保留克制帷幔或浅后殿作为建筑收束，不再留空王座位置。桌侧与后方留连续服务通路。具体移除构件前核查帷幔支架、灯架和柱基支承。

用户已认可照明，本轮规划不以重新布光补救构图；现有后部聚光可继续照亮建筑背景。

## 主座

当前两种 GLB 虽然是分别导出，但来自同一 `chair(throne)` 生成函数，主要改变宽高和菱形数量，因此造型仍是同款。这是设计区分不足。

桌端主座重新设计为低体量、明确等级的宴席扶手椅：较宽的实体背板、端部立柱与冠梁组成完整轮廓；扶手侧板更完整；深木底色上使用少量象牙色嵌板、青铜接头、深红座垫。座高与其他座椅接近，靠背高约 20–30%、宽约 15–20% 作为首稿比例；最终按桌高和远景辨识度调整。普通椅维持细框架与较少饰面。主座不可再仅靠增加同款装饰区别。

六世纪马克西米安座椅可参考木胎覆雕刻象牙板的工艺分层，但它是主教座椅，不是帝王餐椅；不复制宗教人物、铭文，也不宣称复原同一件家具。

## UI：海图边上的书记官用具

当前界面的不协调来自大面积冷绿屏幕边框、重复矩形国名卡片和贴近办公软件的工具按钮。新方案让海图与席位成为主体，控制集中在少量、清晰的屏幕区域。

| 区域 | 新方案 |
| --- | --- |
| 顶部 | 移除整条实色横栏。左上小型地区题签显示国名与进度；右上保留菜单、查看全图，读数用细小文字。 |
| 工具 | 撤去贯穿左侧的底板。底部中央短工具托盘承载亮、暗、擦除、移动；撤销、重做在旁，提示与清错放在次级组。保持操作名称和快捷键。 |
| 国名 | 撤去七块悬浮卡片。总览显示贴合海图的国名字样和小型标记；进度与故事副标题在悬停、键盘聚焦或选中时显示，不同时占满地图。地区近景收起无关标签。 |
| 剧情 | 左下窄幅折页式摘记显示短句与阅读入口。引导时扩展为明确的操作提示；全文进入独立阅读层。 |
| 弹窗 | 菜单、提示、故事、完成反馈共用羊皮纸正文、深墨文字和克制金属框；统一重设计，避免只换主界面皮肤。 |

色彩：炭木 `#261C17`、暖羊皮纸 `#DDCAA3`、深墨 `#332A21`、旧青铜 `#8D6C3C`、绛红 `#742F2C`、象牙白 `#F0E4CA`。字形：国名使用中易宋体／Songti SC 回退；正文与操作说明使用系统中文无衬线；数值用等宽数字特性。标题不逐字拉开，正文不做伪古文。

标志性元素仅保留“小型封印形选中标记”，不为每个按钮堆叠卷轴、宝石或发光框。地图内文字使用受场景光照的世界平面，交互仍提供同步的 DOM 命中区与键盘入口；屏幕控制保持清晰 HTML，只用材质色、边缘和排版与场景协调，不把所有按钮强行放入 3D。

窄屏工具分两组排列；44px 触摸目标；国名保留、冗余副标题收起。引导、工具、剧情条的实际高度必须进入相机可见空间计算。

## 实施顺序与验收

1. 移除双主座布局，确认完整房间构图、桌高与服务通路。
2. 单独设计并建模桌端主座，再与普通椅同框检查轮廓区别。
3. 重设计 UI 全部状态：总览、聚焦、引导、标记、提示、阅读、菜单、完成。
4. 在四种既定尺寸验证无遮挡、命中正确、读数清晰、地区居中和当前存档可恢复。

本次已经完成：隐藏 `lightEditorButton`，不修改灯光参数或存储。后续空间及 UI 实施以上述方案为基础；此文件不代表模型或界面已经重做。
