# 宴厅整体第四稿 — 2026-09-08

本轮把上一轮器物候选纳入独立宴厅试稿，并扩展到建筑、帷幕、材质和布光。正式游戏及存档逻辑不变，没有提交或推送。

- 补上完整浅拱顶和内嵌顶板，增加墙裙、石材立柱分缝、檐口和地面细嵌线。
- Blender 5.2.1 无头导出御座背幕、两侧收拢帷幕和波形华盖垂帘，替换原有简单帘面。新 GLB 为 794,468 字节，不带额外图片贴图。
- 灰绿色石材提亮、降低噪声；保留 2K 木材贴图，降低颜色亮度、清漆高光与法线强度；桌旗降低高频对比。
- 窗面调为冷灰蓝，环境反射降至 0.55，烛光基准强度 30 → 18，保留同步波动和两盏缓存阴影。御座新增无阴影暖色局部光，不增加阴影图数量。
- 默认使用 Blender 盘、杯、餐巾；`?craft=classic` 仅对照旧器物，仍使用新版建筑与灯光。旧版整体保留在历史截图中。远景后退并抬高注视目标，纳入更多御座与华盖。
- 实测发现拱顶遮住总览后，增加随镜头高度 14.5–18.5 平滑淡出的屋顶处理，包含拱肋和顶板。总览时完全隐藏；近景在拱顶下方正常显示。顶层装饰不投影，避免隐藏后仍遮挡光线。
- 入口与修改模块使用 v4.2 资源标识，避免预览缓存保留旧相机、材质或屋顶处理。截图为优化 JPEG，评审页延迟加载非首屏图片。

## 重建

`./tools/Build-BlenderTableware.ps1 -Study Hall` 调用 `tools/build_blender_hall.py`，使用隐藏窗口、BelowNormal、两个逻辑处理器和 `--background --factory-startup --threads 2`。没有外部资源、付费插件或模拟，导出后立即退出，不使用 GPU 离线渲染。
