# 海图第七稿

需求：统一海图、关卡分区、棋盘 UI 美术与光影，修复纸面遮挡烛台。

实现：新象牙纸海图以新版格子归属的色块参考生成；保持七国布局，河流式疆界。正式连续关卡生成器做低频坐标变形，保留 32×24 正方格、七区连通、佩尔 48 格。重新求解生成线索并同步无答案的试稿快照。海图与棋盘坐标统一于 atlas-layout，海图雕刻区作纵向 UV 校准。手绘海岸与方格分界大致对应，不保证像素重合。

棋盘：受光 MeshStandardMaterial，接收实时阴影，哑光、无自发光，半透明纸底、棕墨界线、暗绿/淡金标记，数字局部浅纸底保证辨认。屏幕导航继续保持 HTML 可读性。

烛台：四支位于海图留白内，底座底面贴纸，整根烛台和火焰随高度调整。接触面局部纸张压平，距离交互格子保持净空。第五支保留桌面接触。实时阴影灯数量不增加。

验证：87 项测试通过，包括全部 768 格拾取、正方格尺寸、材质接收阴影、底座净空与纸面接触；七国直接推理和 MiniZinc 唯一解通过；所有试稿 mjs 的 node --check 通过。正式关卡仍为 236 个可见线索。浏览器 CUA 初始化失败，未宣称完成网页视觉、移动端或 FPS 验证。

兼容：已有存档的数据 fingerprint 与新版不同，旧档不能继续载入新版；未调用或清除存储。未推送、未部署。
