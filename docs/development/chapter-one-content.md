# 第一章内容化与国别图案契约

状态：已实现并验收
完成日期：2026-08-30
对应版本：`0.9.0`

## 目标

“内海七国”不再只是七块颜色不同、答案来自随机纹理的区域。每个国家都拥有一幅由自身地理、器物或陷落记录派生的亮暗图案；玩家完成该国时，终局图案、地图显影说明、固定史年与亡国记录共同构成一次完整的内容揭示。

本轮不改变已经拍板的叙事结构：晚宴仍按完成国家总数线性推进，国家仍可自由选择，亡国记录仍以独立故事卡弹出，最后一张记录归档后才出现后世尾声。

## 生成契约

1. `varos_table/content.py` 是国别图案 ID、双语图案名、固定史年和叙事正文的内容源。
2. `varos_table/motifs.py` 在每国自身边界框内使用归一化坐标绘制图形；更换某国的 `mapMotifId` 只能改变该国的目标格。第一次生成使用原始图形场，只有候选无法通过逻辑验收时，后续尝试才对整幅图案加入小幅、可复现的坐标平移与切变；默认 100 次尝试中，任一国家相对原图改变的格子不得超过 25%，扰动不得退化回逐格随机纹理。
3. 每个国家严格取其图形评分最高的一半格子为亮格，因此亮暗数量最多相差 1。图案不能以破坏密度均衡换取可识别性。
4. 图形生成后仍走同一条关卡管线：计算受国界裁剪的 3×3 线索、删去冗余线索、由公开单数字规则从空盘直推，再由 MiniZinc 排除第二解。
5. 正式公开 JSON 只包含 `mapMotifId`、双语图案说明、国界与线索，不包含 400 格目标答案。
6. 图案属于关卡答案的一部分。任何图形修改都会改变关卡指纹，使旧存档安全失效；修改后必须重新运行 `npm run generate`。

## 玩家揭示闭环

国家完成后，棋盘保留全部正确亮暗格并锁定该国。随即弹出的亡国记录按以下顺序呈现：

1. 国家、首都或代表城市与地理；
2. 该国在征服史中的固定年代；
3. 刚刚复原的图案名与地图显影说明；
4. 亡国经过；
5. 留存至后世的物件、习俗或地名。

“地图显影”使用现有故事卡中的内嵌信息块，不增加第二个弹窗，也不把常驻说明塞回主页面。关闭故事卡后，记录照旧进入地图档案。

## 防回归要求

- 七个 `mapMotifId` 必须互不相同，且每个图案名都同时提供 `zh-CN` 与 `en`。
- 自动化测试必须证明更换单个图案声明只改变对应国家，并维持逐国亮暗均衡。
- 正式关卡必须继续覆盖线索 `0—9`，七国均为 `basic` 直推，且 MiniZinc 的 `uniqueVerified` 全部为真。
- 生成后的目录难度报告必须继续通过；内容化不能靠偷偷引入猜测或高级差集推理完成。
- 修改图形公式后除运行测试外，还应检查七国完成态的整体轮廓；数值契约只能防止逻辑退化，不能替代视觉判断。

## 验证命令

```powershell
npm run generate
npm run report:difficulty
npm test
```

`npm run generate` 需要安装带 Gecode 的 MiniZinc。当前第一章仍是 20×20 的内容垂直切片；更大棋盘、更多国家、最终插画动画与商用品质文本编辑留给后续里程碑。
