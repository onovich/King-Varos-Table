## 最重要的实际卡点

### 1. 数字快捷键与帮助文字的契约不一致（中等，实测可复现）

动作：帮助写“1/2/3/4 选择工具，方向键移动格子，Enter 使用工具”。我在已标暗的第11行第31列按 1，预期只切换亮格工具，再方向移动到目标格按 Enter。实际原来焦点格已被改亮，目标格也被 Enter 改亮，清除错误报告移除了两个错误。

进一步确认：在焦点格为亮格时按 2，格子直接改暗；随后按 3，格子立即恢复未知，进度 2/48 变 1/48。这个行为可被熟练玩家利用，但“选择工具”文案会让新玩家不知不觉改掉上一格。建议快捷键只选工具，或明确写为“选择并在焦点格标记”，且使焦点视觉更明确。

### 2. 第一国完成弹窗初始视图落在中下部（中等，单次观察）

最后一格完成后，焦点在“展开内海”。首次截图中标题与正文开头在上方不可见，直接看见正文后半、图景与继续按钮；需向上滚动才能看到“小岛先被记住”和年代。这使剧情奖励容易被快速略过。可能与自动聚焦末尾按钮有关，但未读代码，不能断言实现原因。建议弹窗出现时保持顶部可见，同时保留键盘可达性。

### 3. 自主阶段提示只保持到首次落子（轻微，实测）

阿斯帕 0/96 点击提示，看到第1行第12列零线索和同国四格框；右键标记两格后高亮与提示说明消失，底部恢复佩尔岛蟹汤纪事。预期是能沿提示完成四格再退出；实际需要记住范围或重新提示。第一国引导会继续指示下一组，这种变化有一点突然。建议让提示保持至该范围处理完成，或提供固定提示选项。

### 4. 帮助的关闭不会返回菜单（轻微）

菜单 → 玩法与操作 → Escape，实际直接回棋盘，想继续查看菜单项目必须重开。没有丢失进度，属于额外一步。

## 优点与手感

- 开始后直接聚焦最小岛与一个零，短句明确包含数字格自身、只计本国；随后用边界五格满数解释裁剪计数。21/48 后放手，学习阶段有实际成果。
- 亮金、深青暗格、粉色未知可区分，粗国界清楚；右侧数字链可以自然连续推理，首国无需额外点击提示即完成。
- Ctrl+Z / Ctrl+Y 实测有效；连续拖划两个格只需一次撤销，重做恢复两格。鼠标右键标暗不弹上下文菜单。移动工具拖动后进度不变；聚焦可找回当前国家，滚轮可以缩放。
- “清除错误”明确保留正确标记，实测清除两个错误、保留一个正确零格；错误时底部提供可行动的纠错建议，没有失败惩罚。
- “从头试玩 · 保留原进度”的独立存档说明非常安心；实测重玩回到 0/48，菜单“返回原进度”恢复 1/7。刷新出现“继续旅程”，继续后仍为已复原，存档恢复可靠。
- 第一国完成后自动展开七国图，国家名和各自格数可直接点击，下一步容易找。阿斯帕的 96 格相较 48 格也能清楚预判工作量。
