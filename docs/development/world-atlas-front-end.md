# 封印地图册：世界地图前端契约

日期：2026-08-30  
状态：可交互前端已实现；正式填格玩法仍待挂接。

## 用户模型

1. 顶栏的一枚印章代表一个**国家**。点击印章，地图视口会聚焦该国，印章和右侧故事板同步切换。
2. 所有国家在一个受限、可平移缩放的世界地图中拼合。它不是无限数据地图，但用户可在限定画布里连续移动，不会被切换页面打断。
3. 国家内部的较细格线代表**地区**；国家之间的粗边线始终只落在共享的水平／垂直格边上。
4. 当视口中心移动到另一国，顶栏印章、当前国家卡与右侧故事自动同步。
5. 每国拥有独立的事件索引。切换国家不会重置另一国正在阅读的事件；当前事件显示在右侧故事板。

## 当前入口与交互

- 默认入口：`http://localhost:4173/`，显示“封印地图册”世界导航。
- 旧的可玩逻辑棋盘保留在：`http://localhost:4173/?mode=puzzle`。
- 鼠标滚轮／触控板滚动：围绕指针位置缩放地图。
- 鼠标主键按住拖动：平移地图；单击国家区域可选择该国。
- 键盘：地图获得焦点后，方向键平移，`+`／`-` 缩放，`0` 回到当前国家。
- 顶栏国家印章支持 Tab、左右方向键、Home 和 End。
- 左侧亮格／暗格／擦除工具已经具有独立的选择状态与无障碍状态；当前仅作为玩法接入预留，并不改写格子。

## 文件与数据边界

| 文件 | 职责 |
| --- | --- |
| `web/world-atlas-data.mjs` | 世界尺寸、七国位置／形状、国家内地区、双语故事事件、可本地化文案。 |
| `web/world-atlas.mjs` | 渲染世界格网、严格格线国境、镜头夹取、滚轮缩放、拖拽、国家自动同步、独立事件线。 |
| `web/index.html` | 世界地图、左工具栏、顶栏印章、右故事板的语义结构。 |
| `web/styles.css` | 选定原画的深墨／暖纸／蜡封／昼夜工具视觉；无鱼鳞、点阵、织物或纸浆纹理。 |
| `web/app.js` | 在默认地图入口与 `?mode=puzzle` 旧棋盘之间切换；将语言切换传递给新地图。 |

`web/data/levels/inner-sea.json` 的 `regions` 仍是旧版 20×20 逻辑关的“国家”单位。世界地图的 `districts` 是新的展示层级，当前不应把两者直接混为同一个数据字段；接入实际玩法时，应建立显式的 `countryId → level/board` 映射。

## 给玩法层的接入点

国家变化会在 `#atlasExperience` 上派发事件：

```js
document.querySelector("#atlasExperience").addEventListener(
  "atlas:countrychange",
  ({ detail }) => {
    // detail.countryId
    // detail.country
    // detail.source: "tab" 或 "map"
  },
);
```

`createWorldAtlas()` 还保留 `focusCountry(countryId, { scale })`、`getState()` 与 `setLocale(locale)` 三个方法，供后续容器使用。世界画布的镜头状态与玩法状态刻意分离：玩法层只需根据当前 `countryId` 装载对应棋盘，不应自行重置地图镜头。

## 下一步接入顺序

1. 为每个国家建立独立的关卡／存档键，包含国家内地区、棋盘状态和事件推进。
2. 用真实地区数据替换当前展示用的 `districts` 分割；国境和地区边均继续由共享格边生成。
3. 在当前国家获得焦点时，挂载该国的逻辑棋盘；拖拽仍先由世界地图处理，格内点击再交由玩法层处理。
4. 将 `eventIndexByCountry` 写入国家存档；当前实现只在本次页面会话中保留，以便先验证并行事件线行为。
5. 将故事事件的推进条件与国家完成度、地区完成度或特定逻辑里程碑连接。
