# 连续拖涂契约

状态：已实现并验收<br>
完成日期：2026-08-30

## 目标

让鼠标和触控笔玩家可以一笔处理多个格子，同时保持既有单击、键盘、故事结算和撤销语义不变。

## 玩家契约

- 鼠标或笔在格子上按住并拖动，会把经过的可编辑格统一设为本笔目标状态。
- 本笔目标在按下时确定：从未知格开始使用亮／暗工具会连续填入该状态；从同状态格开始会连续擦除；擦除工具始终写入未知。
- 同一笔重复经过某格不会再次翻转；快速跨过多个格子时会补齐网格路径中的中间格。
- 已完成国家仍然锁定，拖动路径穿过时不会改变其中格子。
- 一整笔只写入一项撤销历史。若一笔完成国家，格子、锁国和叙事状态仍作为同一原子步骤恢复。
- 右键起笔仍直接使用暗格工具，Shift+左键同样如此。

## 触摸边界

触摸继续采用轻触落笔，并保留页面和大棋盘的单指滚动。当前不把触摸滑动解释为涂色，以免 20×20 棋盘失去可靠平移；后续应为触摸拖涂设计明确的模式切换或长按手势，而不是直接禁用滚动。

## 代码边界

- `web/paint-stroke.mjs` 不依赖 DOM，负责固定目标状态、去重访问、跳过锁定格以及用网格线补齐稀疏指针样本。
- `web/app.js` 通过 Pointer Events 管理按下、移动、抬起和取消；拖动期间只更新视觉格，结束时统一分析、持久化、结算并提交历史。
- `tests/test_paint_stroke.py` 从公开笔划 API 和页面事件契约两个边界防止回归。

## 验收结果

- 自动化测试覆盖固定填色／擦除目标、不可编辑格、重复经过、输入数组所有权、横竖对角补线、Pointer Events 接线，以及抬笔坐标在提交前的最终刷新。
- 浏览器实测四格连续填色、固定擦除、暗格拖涂、六格快速补线和鼠标单击；每笔均可一次撤销。
- 使用一笔暗格拖涂补完教学关最后六格后，结算正常出现；撤销一次退回 30/36 并解除锁定，重做一次恢复 36/36 且不重复弹结算。
- 浏览器控制台无警告或错误。
