# 宴厅视觉接入正式玩法（第八轮）

正式入口：web/index.html（http://127.0.0.1:4188/?revision=8）。试稿地址继续保留，但正式入口现已采用 3D 宴厅。

## 实现

- journey-app 继续拥有会话、引导、历史、唯一自动存档、提示、完成判定、剧情与菜单；journey-three 仅渲染会话快照和相机，交互通过射线回到原有输入适配器。隐藏的语义棋盘保留键盘与辅助技术描述。
- 正式关卡和练习地图都使用实际加载的宽高、分区、线索与标记；不使用试稿本地 marks 作为游戏进度。动态棋盘更新同步提示范围和当前区域。
- 所有实际 3D 相机写入集中到同一个按帧间隔计算的指数平滑器。滚轮、拖动、捏合、聚焦、全图、返回标题和窗口变化只更新目标。新目标从当前实际镜头继续，无跳位。2D 相机存档结构保持兼容。
- 烛光 nominal intensity 从 18 增至 52；同一闪烁信号驱动火焰与灯光。HDR 环境强度 .85→.52、主光 1.25→.9、半球 .50→.27、填光 .35→.20。仍仅两盏缓存点光阴影，无新增实时阴影灯。菜单提供烛光动态开关，默认遵守减少动态效果偏好。
- 全部场景资源 URL 以模块地址解析，可由正式根目录和试稿子目录共同加载。离线依赖仍在项目内，无 CDN。
- 手机阅读栏与工具栏分行；国名标签限制在屏幕内；聚焦考虑标题栏和阅读栏遮挡。

## 验证

- 89 项 unittest 通过，包括 30/60 FPS 下平滑一致性、运动中目标切换、三个视口比例全部 768 格的透视拾取、实际会话标记→撤销→重做→序列化恢复→3D 显示。
- 所有一层 web 和试稿 mjs 通过 node --check；git diff --check 通过。
- 本轮 CUA 已恢复。实际浏览器验证：3D 标题→新旅程→佩尔岛引导；点击第10行32列的0并标暗，正式进度 0→1；撤销 1→0、重做 0→1；刷新出现回忆往昔，恢复 1/48；擦除回到0/48；跳过引导、七国导航、切换阿斯帕、聚焦、滚轮缩放、返回标题。
- 1280×720、390×844、320×740 实际检查。手机检查发现并修复工具栏被说明区覆盖及标签超出边缘。未进行真实手机触摸设备测试。
- 当前桌面测试机器在桌面和模拟窄屏均采样约60 FPS，浏览器控制台没有 error/warn。属于短时 rAF 采样，不是全面性能基准，不代表手机实机帧率。
