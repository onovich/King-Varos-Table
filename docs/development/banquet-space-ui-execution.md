# 宴厅空间与 UI 实施记录

2026-09-09，revision 10。仅本地修改，未推送或部署。

## 交付

本地入口：http://127.0.0.1:4188/?revision=10&level=inner-sea-journey-v1

- 删除远处王座、多级台阶及旧华盖构件。七席为六个侧席加一个桌端帝王席，背墙保留浅框架与帷幔。主座采用独立木作背板、三联象牙色嵌板及冠梁；普通椅子共享模型。
- Blender 隐藏无头、低优先级、双线程生成；当前水果、桌面材质及照明参数保持原状。
- 移除大面积绿边栏，改用纸面地区题签、底部木色青铜工具托盘与窄剧情摘记；菜单、阅读窗和标题配色统一为纸、墨、木、青铜。
- 总览隐藏网格和数字；国名以接受光照的平面文字绘在海图上，悬停或键盘聚焦展开进度。地区聚焦恢复棋盘，并保持其他地区暗化。
- 相机取景避开顶部与底部 UI；修复 320 像素窄屏固定阈值导致选区后未进入可操作聚焦的问题，保留缩放滞回。
- 正式菜单隐藏光影编辑入口，保留原调光功能及独立配置兼容性。谜题、分区、剧情和存档格式未改动。

## 验证

`python -m unittest discover -s tests`：95 项通过。新增真实 GLB 七席数量、主座尺寸与桌端净空检查；补充窄屏聚焦阈值和滞回断言。既有玩法、光照配置、模型净空、遮罩与相机测试通过。

实际浏览器检查 1440×900、1280×720、390×844、320×740：标题、读档、总览、地区切换、聚焦、阅读与菜单。最窄屏工具两行排列，菜单完整可达；320 像素聚焦修正后实际复验。读回存档阿斯帕仍为 2/102，选区未额外落笔。本轮未通过新旅程覆盖用户存档；未手动改写标记来重复测试撤销。浏览器未观察到加载错误。
