# 第一国陷落垂直切片

状态：已实现并验收
批准日期：2026-08-28
完成日期：2026-08-28

## 目标

把当前已经可靠的逻辑谜题原型推进成第一段完整游戏体验：玩家打开一张由七个国家组成的地图，自由选择国家推理；某国完成后，地图留下永久变化，弹出该国的亡国故事卡，晚宴纪事继续向前，并在刷新页面后恢复进度。

这个里程碑验证的重点不是增加更多推理规则，而是确认“解开一个区域”能否自然地成为“复原一个国家及其历史”的游戏动作。

## 已拍板的产品决定

1. 下一里程碑采用“第一国陷落”叙事垂直切片。
2. 第一张正式地图使用固定设计的七个不规则、四向连通国家。
3. 国界只能沿格线行走；棋盘仍为 20×20，所有区域共同裁剪在一个矩形外框内。
4. 每个国家必须分别通过默认单数字直接推理验收，并由 MiniZinc 排除第二解。
5. 玩家在第一章内可以自由选择国家；晚宴按已完成国家总数线性推进。
6. 完成国家必须弹出独立故事卡；关闭后进入档案并可重读。
7. 地图本体必须永久表现该国已经完成，不能只依赖弹窗。
8. 棋盘、国家完成状态、故事档案与晚宴节点使用版本化本地存档。

## 完成定义

- 公开关卡 JSON 包含七国地图、国家元数据、晚宴节点和亡国故事卡，但继续隐藏目标答案。
- 七个国家均连通，面积存在明显差异，最小国家承担较早触发第一次揭示的职责。
- 当前提示、检查、清除错误、区域筛选和重置功能在七国地图上继续成立。
- 国家只有在该区域所有格子都已正确确定后才算完成。
- 同一国家的首次完成只触发一次新故事卡；从档案重读不重复改变进度。
- 晚宴节点只随完成国家总数向前推进，不因玩家自由选择国家而倒退。
- 有效存档在刷新后恢复；版本、关卡或数据不匹配的存档安全忽略。
- 故事卡使用可关闭的语义化对话框，打开时获得焦点，关闭后把焦点交还给合理的触发控件。
- 320 px 宽度仍可操作；棋盘允许横向滚动，弹窗正文不会逃出视口。
- 现有提示系统守则及其防回归测试全部保留。

## 本轮不解决

- 完整战役、最终国家数量和全部章节；
- 程序随机生成国家轮廓；
- 最终插画、纹章和商用品质故事文本；
- 高级双线索提示作为默认玩法；
- 英文内容、本地化流程和公开发布。

## 测试边界

- Python 关卡接口：区域连通性、七国面积、公开数据、直接可解与 MiniZinc 唯一性。
- 浏览器逻辑接口：国家完成协调、晚宴节点、只触发一次的故事队列和版本化存档。
- 用户可见 DOM：固定档案入口、语义化故事对话框、无动态布局挤压、必要的 ARIA 标签与状态文字。

## 实现结果

- 固定七国关卡已生成；七国均由默认单数字直推从空盘完成，并由 MiniZinc 排除第二解。
- 国家完成、地图锁定、晚宴推进、首次故事揭示、关闭后入档和档案重读已经形成闭环。
- 存档使用版本号和关卡内容指纹；国界、线索、国家故事或晚宴数据变化时不会套用旧进度。
- 完成历史只会通过明确的“重新开局”清空，不会因普通协调或刷新倒退。
- 档案入口始终保留布局位置；第一次故事揭示前只显示中性的“地图档案尚未整理”并禁用，关闭故事卡后才改为可用的亡国档案入口。
- 自动化测试共 22 项；浏览器实测覆盖首次完成、关闭后入档、刷新恢复、无重复弹卡、控制台错误和 320/768/1024/1440 px 响应式布局。
