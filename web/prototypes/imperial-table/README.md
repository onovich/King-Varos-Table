# 盛宴将启 · Three.js 视觉交互试稿

独立入口：`http://127.0.0.1:4175/prototypes/imperial-table/`。从仓库根目录运行 `python -m http.server 4175 --directory web` 即可预览。

这是七席宴厅、写实海图底材、材质光影与镜头交互试稿。第二稿加入真实内海棋盘的独立快照与可试填 UI；没有接入游戏入口、答案、存档或剧情进度。刷新回到宴席远景并清空试填。所有资源由本地 HTTP 提供。

## 操作

- “俯瞰海图”：约 1.4 秒进入总览。
- 远处悬停显示国名；点击地区或底部国名，以约 700 毫秒 ease-out 聚焦。
- 靠近时真实 32×24 棋盘及 236 个原始数字线索渐显，远离时淡出；每格的屏幕尺寸驱动显现，地图图像本身没有网格。
- 近处用亮格、暗格、擦除点按标记，撤销回退；移动工具不标记。方向键选择格子，空格按当前工具标记，1/0/Delete 直接标记。试填仅驻留内存。
- 拖动平移、滚轮缩放；触屏单指平移、双指缩放。
- 拖动超过 6 CSS 像素和多指操作不会触发选区；直接操作取消当前运镜。
- “查看全图”与“返回宴席”切换视角；国名按钮支持 Tab、左右方向键、Home、End、Enter。

## 文件与依赖

- `scene.mjs`：实际宴厅、桌面、器皿几何体，程序化环境反射、木纹与海图纹理，阴影和烛光。
- `map-data.mjs`：七国名与相机落点，选区沿用快照的地区分布。
- `board-data.mjs`：正式内海关卡的只读布局与可见线索快照，不含答案。
- `board.mjs`：独立透明棋盘平面、坐标拾取、渐显、标记和撤销。
- `materials.mjs` / `craft.mjs`：材质、倒角、盘盏装饰、杯纹、蜡滴、织物、柱头与檐线。
- `assets/sea-chart.png`：内置 imagegen 生成的海图底图；[生成提示词与来源](assets/PROMPT.md)。
- `camera.mjs` / `motion.mjs`：构图终点、插值及可中断动画。
- `app.mjs` / `style.css` / `index.html`：输入、生命周期、屏幕空间 UI。
- `vendor/three.module.min.js`、`three.core.min.js`：npm 官方包 `three@0.185.1` 的构建产物；MIT 许可证保存在 `vendor/LICENSE`。没有 CDN 或外部模型依赖。

桌面像素比上限 1.75、阴影 2048；宽度不超过 700 时分别为 1.25、1024。只有主方向光开启实时阴影。隐藏页面停止动画；减少动态效果设置将运镜缩短到 120 毫秒并停止烛光变化。模块加载失败、WebGL 创建失败和上下文中断均有错误说明。

## 第二稿验证补充

按新的要求取消首稿“不显示数字与网格”的限制，将背景美术和实际棋盘分离。海图是一张独立羊皮纸纹理，不表达棋盘边界；棋盘渲染与拾取共享实际 768 个格子的坐标。纹理独立替换不会改变格子位置或线索。

新增验证：所有 768 个格子的 UV/索引往返、七区快照与正式关卡逐项一致、236 个线索一致、远近渐显阈值、亮/暗/擦除/撤销和刷新独立状态。`npm test` 共 78 项通过。浏览器实际点按同一格完成亮→暗→撤销恢复亮→擦除。

材质与几何已细化，但仍是程序化资产的视觉试稿，不把这次改进宣称为最终写实品质。手机实机性能、真实双指输入仍待验证。

第二稿检查 1440×900、1280×720、390×844、320×740；窄屏采用较近的地区镜头保证棋盘和工具达到可操作显现阈值。纸面和网格分属两个平面，背景图更换不影响数字、格线或点击坐标。

第二稿截图：[宴席](screenshots/banquet-v2.jpg)、[海图](screenshots/overview-v2.jpg)、[棋盘](screenshots/region-v2.jpg)、[390 窄屏](screenshots/mobile-board-v2.jpg)、[320 窄屏](screenshots/narrow-board-v2.jpg)。

第二稿桌面短时观察约 58–60 FPS，标记会重绘棋盘纹理；这不是手机性能结论。浏览器已验证近景标亮/标暗/擦除/撤销，拖动不误填，总览隐藏工具；78 项测试保持通过。

## 第三稿：扫描材质、食物与御宴厅

- 桌面替换为 2K 实拍木材颜色、法线、粗糙度三张贴图，取消程序木纹。
- 苹果、石榴、面包替换为本地 glTF 扫描资产，保留自然轮廓、果蒂、果皮与酥皮层次；原有球形水果和扁球面包已移除。
- 新增御座高台、华盖、褶皱帷幔、抽象日轮冠饰、拱廊、穹顶肋骨、壁板和悬挂灯架，调整远景镜头。
- 杯中酒液增加弯月面、透射、吸收与低粗糙度反射；壶中液体采用匹配容器的体积轮廓。玻璃不再投射不透明实心阴影。
- 烛火为立体渐变火焰网格，底部锚定烛芯，轻微形变；每支暖色点光源与火焰共用波动参数。两支蜡烛使用 512 像素缓存立方体阴影。蜡体不作为不透明遮挡体，以避免点光源在桌面制造过大的黑色圆斑。器皿和烛台仍投影。
- 火焰不是流体模拟；缓存阴影适用于本试稿静止的器物。如果未来移动器物或光源位置，需要显式刷新这些阴影。

全部新资源本地加载；来源、授权与 Blender 检查结果见 [资产记录](assets/CREDITS.md)。没有找到本机 Blender 可执行文件，本轮没有使用 Blender，也没有安装它。

验证：80 项自动测试通过，新增本地 glTF 完整性、加载器依赖与火光波动／减少动态效果契约测试。桌面短时观察仍约 60 FPS，手机实机性能未验证。初次 glTF 加载遗漏 SkeletonUtils 的问题已补齐并通过导入测试。

第三稿浏览器检查：1440×900、1280×720、390×844、320×740；进入海图、近景、点击标记、拖动与返回正常。桌面短时观察约 60 FPS。四视图与两张窄屏截图见 [对照页](review.html)。完整手机硬件帧率与热稳定性仍未验证。
